## Attribution without publishing your personal name

The public project files use **TrueDuck Security** as the author pseudonym and
brand. The public notice is a project credit, not a legal incorporation record.
A person may publish software under a pseudonym, but a pseudonym does not
transfer copyright ownership or establish rights in code that person does not
own. The author should review rights in their own contributions and any
third-party materials before a public release.

You may be asked for private legal identity information by a marketplace,
payment provider, registrar, or authorities even if the public byline remains
TrueDuck Security. Do not put personal identity information into a public Git
repository just to satisfy this project's branding requirements.

## What the Apache 2.0 license means

Where you hold copyright or have authority to license content, Apache 2.0
allows others broad rights to use, modify, and redistribute it, including
commercially, subject to the license. These permissions generally cannot be
withdrawn from properly licensed copies. Open-source code does not include
private user reports, actual database content, passwords, or other secrets.

The **TrueDuck Security** name and brand identity are separate from the code
license; see `TRADEMARKS.md`. No claim is made that the mark is registered.

## Before making the repository public

1. Ensure you have the authority to release the included code, artwork, and
   any third-party components under their respective terms.
2. Inspect the entire upload for private files and credentials, including any
   prior Git history. A `.gitignore` file does not remove files already committed.
3. Check the actual data-handling behavior against `PRIVACY.md`; that file is
   still a **development draft**, not a publicly compliant privacy policy.
4. Keep servers local until HTTPS hosting, abuse protection, backups, and
   independent security review are completed.
5. Make the first GitHub release a **pre-release** with tag `v0.9.2-beta.1`.

The exact legal ownership of human-authored and AI-assisted contributions may
vary. This document is informational guidance, not legal advice.
