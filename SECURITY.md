# Security and vulnerability reports

This is an experimental open-source project. Please avoid posting credentials, private reports, or exploit details in public issues. If the repository has a private vulnerability-reporting option, use that channel; otherwise contact the maintainers through a private channel before disclosing sensitive findings.

Do not deploy the local development servers directly to the internet. Run the static preflight and automated tests before releasing new builds. These checks do not constitute a security audit.

Anonymous reporting requires no login. Only the locally created owner may moderate. Do not enable public intake on the internet until shared rate limits, abuse moderation, retention policies and hosting log privacy are reviewed.

The legacy private server and bulk feed upload are retired. Only authenticated owner moderation endpoints can approve or publish community reports. The extension stores no administrator token and uses only the configured public feed.
