# START HERE — new `trueduck-sentinel` GitHub repository

1. Open GitHub Desktop, clone your **private** `trueduck-sentinel` repository.
2. Open this extracted folder, select and copy **the contents** (not the parent folder).
3. In GitHub Desktop, select **Repository → Show in Explorer** and paste into the cloned repository directory.
4. Verify `README.md`, `LICENSE`, `extension/`, `backend/`, `cloud_api/`, and `tests/` appear at the **top level**.
5. Review GitHub Desktop's **Changes** list for secrets or personal information.
6. Run `CHECK_SECURITY.cmd` after installing Python dependencies if needed.
7. Commit `Initial TrueDuck Sentinel Beta source` and **Push origin**.
8. Keep the repository private pending code, privacy, and release review.

To try the consumer experience, visit `edge://extensions`, enable Developer mode, choose **Load unpacked**, and select the root `extension` folder. No account or Python server is needed for the extension's local text-based warnings. Live public reputation data requires deployment of the separate API.

See `GITHUB_START_HERE.md` for details and `BRAND_AND_DOMAIN.md` for the renamed product and compatibility identifiers.
